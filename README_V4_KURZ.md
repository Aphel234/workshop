# Workshop-Zuteilung – Version 4

Diese Version erweitert die GitHub-Pages-Anwendung um flexible Zuteilungsregeln, eine verständlichere Steuerung des Kursgrößenausgleichs und eine interaktive Kursdetailansicht zur manuellen Nachbearbeitung.

## Leitlinie
Die Hauptoberfläche bleibt einfach. Erweiterte Regeln sind eingeklappt und standardmäßig **Bevorzugt** statt **Hart**.

## Regeln
Unterstützt werden Mindestgruppen pro:

- Klasse
- Jahrgang
- Jahrgang + Bildungsgang
- Jahrgang mit mindestens einem ausreichend großen Bildungsgang

## Belastungsausgleich
Voreinstellungen: Aus / Leicht / Mittel / Stark. Zusätzlich kann eine Maximalgrößen-Schwelle gesetzt werden, sodass bewusst kleine Kurse nicht mit großen Kursen ausgeglichen werden.

## Nachbearbeitung
Kurse sind in der Ergebnisübersicht anklickbar. Die Detailansicht zeigt Zugeordnete, Anwähler, Regeldetails, manuelle Verschiebung, Festsetzen, Undo und Tauschvorschläge.

## Datenschutz
Teilnehmerdaten bleiben im Browser. Keine echten Schülerdateien in das öffentliche GitHub-Repository hochladen.
